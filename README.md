# 인공지능, 얼마나 알고 있나요? (AI Literacy Quiz & Feedback Web App)

초등학교 5~6학년 학생을 위한 인공지능 기초 소양 점검 퀴즈 및 생성형 AI 맞춤 피드백 웹 애플리케이션입니다. 학생이 퀴즈를 풀고 서술형 생각을 작성하면, Gemini AI가 눈높이에 맞춘 3단계 피드백을 제공하며 학습 기록을 안전하게 저장하고 관리할 수 있습니다.

---

## 1. 앱의 목적과 대상

- **대상**: 초등학교 5~6학년 학생 (어린이 눈높이 UI 및 쉬운 어휘 적용)
- **목적**:
  - 인공지능의 기본 작동 원리(사람이 만든 규칙 기반 vs 대량의 데이터 학습 기반)를 이해합니다.
  - 학습 데이터의 품질과 다양성이 인공지능의 공정성과 정확성에 미치는 영향을 학습합니다.
  - 인공지능이 생성한 결과를 무조건 신뢰하지 않고 비판적으로 검토하는 올바른 활용 태도를 기릅니다.
  - 서술형 응답에 대한 맞춤형 AI 피드백을 통해 자기주도적 성찰과 탐구 능력을 함양합니다.

---

## 2. 주요 기능

1. **인공지능 소양 객관식 퀴즈 (3문항)**
   - 초등 교육과정 연계 3지선다형 퀴즈.
   - 각 문항별 보기 선택 시 시각적 피드백 제공 및 보기를 선택하기 전에는 [정답 확인] 버튼 비활성화.
   - 문항별 즉각적인 정답 여부 확인 및 친절한 해설 제공.
   - 상단 진행률 표시줄(Progress Bar) 제공.

2. **퀴즈 결과 분석 및 다시 풀기**
   - 총점 및 정답 개수 산출, 성취도에 따른 초등학생 맞춤 격려 메시지 표시.
   - 문항별 실제 선택한 답과 정답을 비교할 수 있는 상세 확인표 제공.
   - **완전한 다시 풀기 지원**: 풀이 회차(Attempt ID) 분리 및 상태 초기화를 통해 이전 선택값, 정답 표시, 누적 점수가 남지 않고 완전히 초기화되어 재도전 가능.

3. **서술형 응답 및 Gemini AI 맞춤형 3단계 피드백**
   - 생각할 거리를 던지는 서술형 질문 제공.
   - 서버 사이드 Gemini API를 활용한 안전하고 체계적인 3단계 구조화 피드백 생성:
     1. **잘 이해한 점**: 학생의 응답에서 칭찬할 점과 올바른 이해 요소를 구체적으로 격려.
     2. **더 생각할 점**: 부족하거나 보완할 점을 친절하게 짚어주는 조언.
     3. **이어 생각할 질문**: 더 깊이 탐구해 볼 수 있는 확장 질문 제시.

4. **사용자 인증 (Google 로그인)**
   - Firebase Authentication 기반 Google 계정 로그인/로그아웃 지원.
   - 비로그인 상태에서도 퀴즈 풀이 및 AI 피드백 체험 가능.
   - 학습 기록 저장 및 개인 보관함 이용 시 안전한 사용자 세션 식별.

5. **클라우드 학습 기록 저장 (Cloud Firestore)**
   - 로그인 상태 및 AI 피드백 생성이 완료되었을 때 [학습 기록 저장] 활성화.
   - 저장 항목: 소유자 UID, 활동 ID (`ai-literacy-01`), 질문, 서술형 답변, 피드백 초안, 지침 버전(`v1`), 서버 기준 타임스탬프.
   - 동일 답변 재시도 시 결정론적 문서 ID(SHA-256 해시 기반)를 적용하여 데이터 무결성 보장 및 중복 저장 방지.

6. **‘내 학습 기록’ 조회 및 관리**
   - 로그인한 사용자가 본인이 저장한 기록만 최신순으로 조회.
   - 불필요한 Gemini API 재호출 없이 순수 Firestore에서만 안전하게 읽기 수행.
   - 기록 카드 클릭 시 상세 보기 모달에서 질문, 작성 응답, 저장된 피드백 전체 확인.
   - 데이터베이스 읽기 및 UI 표시 단계에서 소유권(Owner ID) 엄격 재검증.

7. **학습 기록 삭제**
   - 상세 보기 모달 내 [기록 삭제] 버튼 제공.
   - 실수 방지를 위한 사용자 사전 확인 대화상자(Confirmation Dialog) 제공.
   - 취소 시 기존 기록 완벽 보존.
   - 삭제 확정 시 Firestore에서 실제 문서를 삭제하고 UI 화면에서 즉시 제거.
   - 타인 기록 삭제 시도 및 권한 없는 삭제를 원천 차단하는 Firestore 보안 규칙 적용.

## 3. 사용 순서 (User Flow)

1. **시작 화면**
   - 앱 타이틀과 안내를 확인하고 [퀴즈 시작하기]를 누릅니다. (필요 시 우측 상단에서 Google 로그인 가능)
2. **퀴즈 풀이 (1~3번)**
   - 각 문제의 3개 보기 중 하나를 선택합니다.
   - [정답 확인]을 눌러 채점 결과와 해설을 확인합니다.
   - [다음 문제]를 눌러 순서대로 3문항을 모두 풉니다.
3. **결과 확인**
   - 최종 득점(예: 3문항 중 2문항 정답)과 격려 뱃지를 확인합니다.
   - [문항별 확인하기]에서 어떤 문제를 맞히고 틀렸는지 복습합니다.
4. **서술형 작성 및 AI 피드백**
   - 결과 화면 하단의 서술형 질문에 자신의 생각을 작성합니다.
   - [AI 맞춤 피드백 받기]를 눌러 3단계 AI 피드백을 실시간으로 확인합니다.
5. **학습 기록 저장**
   - 로그인 상태에서 [학습 기록 저장] 버튼을 누릅니다. (로그인되어 있지 않은 경우 로그인 안내 표시)
   - 데이터베이스 저장 완료 알림을 확인합니다.
6. **내 학습 기록 확인 및 관리**
   - 화면 상단의 [내 학습 기록] 버튼을 눌러 기록 목록으로 이동합니다.
   - 지난 기록 카드를 클릭하여 질문, 내가 쓴 답, AI 피드백 상세를 열람합니다.
   - 삭제하고 싶은 기록은 상세 창에서 [기록 삭제]를 눌러 확인 후 삭제합니다.
7. **다시 풀기**
   - 결과 화면에서 [다시 풀기]를 누르면 모든 문항 선택과 점수가 깨끗하게 초기화되어 1번 문제부터 다시 도전할 수 있습니다.

## 4. 실제로 확인한 기능 (Verification Scope)

- [x] **객관식 퀴즈 풀이 및 채점**: 1~3번 문제 선택, 보기 미선택 시 [정답 확인] 비활성화 동작, 정답/오답 배너 및 해설 출력 검증.
- [x] **다시 풀기 상태 초기화**: 1차 풀이(2점) → 다시 풀기 클릭 직후 1번 문제의 선택 강조 및 해설 제거 확인 → 답 미선택 시 정답 확인 불가 확인 → 2차 풀이 모두 오답 시 0점 산출 확인 → 3차 풀이 모두 정답 시 3점 산출 확인.
- [x] **Gemini AI 서술형 피드백 생성**: Express 서버 엔드포인트(`/api/feedback`) 프록시를 통한 3단 구성(잘 이해한 점, 더 생각할 점, 이어 생각할 질문) 스트림/JSON 생성 동작 확인.
- [x] **Google 로그인 및 세션 관리**: Firebase Auth 팝업 로그인, 로그아웃, 로그인 상태에 따른 헤더 프로필 표시 및 권한 상태 전환 검증.
- [x] **Firestore 학습 기록 저장**: 조건(로그인 + 피드백 생성 완료) 충족 시 서버 타임스탬프 및 해시 기반 고유 ID로 `learningRecords` 컬렉션에 정상 기록됨을 확인.
- [x] **학습 기록 조회**: `fetchUserLearningRecords`를 통한 최신순 목록 로딩, Gemini API 중복 호출 없음 검증, 로그아웃 시 기록 화면 즉각 초기화 확인.
- [x] **학습 기록 삭제**: 삭제 확인 대화상자 표시, 취소 시 기록 유지, 삭제 확정 시 Firestore 문서 삭제 및 화면 목록에서 즉시 제거 확인.
- [x] **빌드 및 런타임 안정성**: `tsc --noEmit` (타입 체크 에러 0건), `vite build && esbuild` (프로덕션 빌드 성공), Express 헬스체크 (`/api/health` 200 OK) 정상 통과.

## 5. 남은 문제와 제한 (Known Limitations)

1. **브라우저 iFrame 환경에서의 서드파티 쿠키 차단**
   - 개발 도구 iFrame이나 일부 브라우저의 엄격한 추적 방지(사파리 ITP 등) 환경에서는 Firebase Auth 팝업 인증 세션 유지가 차단될 수 있습니다. 정상 동작을 위해 새 탭에서 열어 실행하는 것을 권장합니다.
2. **Gemini API 분당 할당량 및 네트워크 의존성**
   - AI 서술형 피드백 생성은 실시간 네트워크 연결 및 API Key 할당량(Quota)의 영향을 받습니다. 일시적인 네트워크 지연이나 할당량 초과 시 재시도 안내 메시지가 표시됩니다.
3. **Firestore 보안 규칙 준수 요구**
   - `firestore.rules`에 따라 `learningRecords` 컬렉션은 문서의 `ownerId`와 `request.auth.uid`가 일치하는 경우에만 읽기, 생성, 삭제가 허용됩니다. 비로그인 상태이거나 타인의 ID로는 조작이 불가능합니다.
4. **문항 콘텐츠 관리 기능 부재**
   - 현재 3문항의 퀴즈는 수업용 표준 문항으로 설정되어 있으며, 교사용 문항 편집 또는 추가를 위한 별도의 관리자(Admin) 페이지는 포함되어 있지 않습니다.

## 6. 실행에 필요한 서비스와 설정 항목 이름

본 애플리케이션은 **Full-Stack (Express + Vite React)** 구조로 실행되며, 다음 서비스 및 환경 변수 설정이 필요합니다.

### 1) Google Gemini AI (서버 사이드)
서버(`server.ts`)에서 서술형 피드백을 생성하기 위해 사용됩니다. 키 값은 브라우저에 노출되지 않고 백엔드에 안전하게 보관됩니다.
- **환경 변수 이름**:
  - `GEMINI_API_KEY`: Google AI Studio에서 발급받은 Gemini API 키

### 2) Firebase Authentication & Cloud Firestore (클라이언트 & 데이터베이스)
사용자 로그인 및 학습 기록 영구 저장을 위해 사용됩니다.
- **설정 파일**: `firebase-applet-config.json`
- **설정 항목 이름**:
  - `projectId`: Firebase 프로젝트 식별자
  - `appId`: Firebase 웹 앱 식별 번호
  - `apiKey`: Firebase 클라이언트 공개 식별 키
  - `authDomain`: Firebase Auth 인증 콜백 도메인
  - `firestoreDatabaseId`: Firestore 데이터베이스 인스턴스 이름
  - `storageBucket`: 스토리지 버킷 경로
  - `messagingSenderId`: 메시징 센더 ID

### 3) 서버 실행 환경 변수
- `PORT`: 서비스 바인딩 포트 (기본값: `3000`)
- `NODE_ENV`: 런타임 환경 구분 (`production` 또는 `development`)
